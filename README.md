# Random Password Generator

## Project Description

This project is a simple Random Password Generator developed using Python.

It generates random passwords based on the length entered by the user. 
The program uses Python's built-in `string` and `secrets` modules to create
secure and unpredictable passwords.

## Features

- Takes password length from the user
- Generates random passwords
- Uses letters, numbers and special characters
- Uses the `secrets` module for secure random generation
- Validates the entered password length
- Calculates estimated password entropy
- Displays the generated password and its details

## Technologies Used

- Python
- `string` module
- `secrets` module
- `math` module
